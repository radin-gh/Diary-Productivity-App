# Diary & Todo App

An Android application for managing personal diaries and daily tasks through a calendar-based system.

## Features

- Create and manage diary entries
- Attach photos to diary entries
- Calendar-based diary and todo management
- Daily mood/emotion tracking
- Create todo lists for specific dates
- Daily reminders and notifications
- Share diary entries
- Offline data persistence

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Room Database
- MVVM
- Coroutines & Flow
- Android Notifications
